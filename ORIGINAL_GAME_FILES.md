# Оригинальные файлы игры

Этот репозиторий не содержит и не должен содержать материалы оригинальной игры.

Допустимо локально исследовать законно установленную копию, не меняя её и не публикуя результаты, содержащие защищённые материалы. Исходные файлы и результаты извлечения размещайте вне репозитория либо только в каталогах, перечисленных в `.gitignore` (`original/`, `reference/`, `research-input/`, `research-output/` и аналогичных).

Запрещено добавлять оригинальные EXE, DLL, сохранения, карты, музыку, изображения, архивы, тексты, извлечённые ассеты и декомпилированный код. Даже игнорируемые материалы нельзя принудительно добавлять через `git add -f`.

Разрешены небольшие fixtures, полностью созданные авторами проекта в `samples/synthetic/`, при условии что они не воспроизводят оригинальные данные. Наблюдения документируются отдельно от гипотез и подтверждённых выводов. Неизвестное отмечается `TODO-D2-RESEARCH`.

## Локальная конфигурация пути

Переменная окружения `D2_ORIGINAL_PATH` указывает исследовательским инструментам на законно установленную локальную копию. Указывайте каталог вне этого Git-репозитория и никогда не сохраняйте реальное значение в `.env` или другом отслеживаемом файле.

Для текущей PowerShell-сессии:

```powershell
$env:D2_ORIGINAL_PATH = "D:\Research\Disciples2Reference"
dotnet run --project tools/DisciplesRemaster.FileInventory -- validate-path
```

Команда `validate-path` выводит только скрытое представление пути, например `<configured-original-game-directory>/Disciples2Reference`. Она проверяет существование каталога и возможность прочитать его метаданные, не перечисляя содержимое и не подтверждая версию или корректность установки.

Команда `inventory` рекурсивно учитывает каждый обычный доступный файл независимо от расширения, имени, распознанной сигнатуры или предполагаемого назначения. Неизвестный файл также получает размер и SHA-256 и остаётся в категории `Unknown`; категории не являются фильтром. Пропускаются только hidden-элементы без `--include-hidden`, ссылки/reparse points, элементы глубже `--max-depth` и недоступные элементы со структурированным предупреждением.

Оригинальная установка всегда рассматривается как read-only research input. Инструменты не создают, не копируют, не изменяют и не удаляют ничего внутри неё. JSON и Markdown сохраняются только в отдельный output-каталог, который не может находиться внутри оригинальной установки и должен оставаться вне Git.
