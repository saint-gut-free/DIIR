# Native scenario format v1

Это спецификация собственного формата Disciples Remaster Research Project. Она не описывает `.sg` и не является результатом реверс-инжиниринга.

## Назначение

Формат служит единым контрактом между независимым ядром, редактором, persistence и клиентом. Первая версия намеренно содержит только минимальную геометрию и ссылки на проектный контент; игровые правила будут добавляться отдельными версиями после явного проектирования.

## Модель

- `formatVersion` — целое число `1`;
- `id` — стабильный lowercase ID длиной до 64 символов;
- `title` — отображаемое название длиной до 160 символов;
- `description` — необязательный проектный текст длиной до 8192 символов;
- `map.width`, `map.height` — положительные размеры прямоугольной сетки;
- `map.defaultTerrain` — ссылка на проектный контент;
- `map.terrain` — разреженный набор terrain overrides.

Координаты нулевые: `x` находится в `[0, width)`, `y` — в `[0, height)`. В одной позиции допускается не более одного override.

Content reference имеет форму `namespace:name`, использует lowercase ASCII, цифры, `.`, `_`, `-`, а в части name также `/`. Ссылка обозначает только собственный или явно распространяемый контент проекта.

## Защитные лимиты

- максимальная отдельная размерность: 4096;
- максимальное число клеток: 4 194 304;
- максимальная длина content reference: 128.

Это инженерные ограничения версии 1 нового формата. Они ничего не утверждают об ограничениях оригинальной игры.

## Детерминированность

Persistence обязан сортировать terrain overrides сначала по `y`, затем по `x`, а затем по content reference. Один и тот же валидный документ должен сериализоваться в одинаковые UTF-8 bytes независимо от порядка входной коллекции.

JSON использует camelCase property names, отступ в два пробела и завершающий LF. Неизвестные свойства отклоняются, чтобы опечатка не приводила к молчаливой потере данных. Максимальный размер JSON-документа для встроенного file store — 64 MiB.

Запись выполняется через временный файл в целевом каталоге с последующей заменой назначения. Невалидный документ не создаёт и не перезаписывает целевой файл. Родительский каталог должен существовать явно.

## Versioning

Неизвестная версия отклоняется. Новые обязательные поля или изменение семантики требуют новой версии. Добавление версии сопровождается миграцией в `Persistence` и тестами совместимости.

## Граница импорта

Оригинальные форматы могут быть только входом отдельного импортёра. Абсолютные локальные пути, оригинальные bytes и исследовательские артефакты не входят в native scenario document.
