# Grid navigation contract v1

Это контракт собственного движка, а не описание алгоритма или правил Disciples II.

## Ответственность алгоритма

`GridPathfinder` выполняет детерминированный breadth-first search и возвращает кратчайший путь по числу переходов. Результат содержит status, полный путь от start до goal и число посещённых позиций. Поиск ограничен `maximumVisitedPositions`, чтобы повреждённый или чрезмерный input не создавал неограниченную нагрузку.

Поддерживаются statuses:

- `Success`;
- `StartOutsideGrid`;
- `GoalOutsideGrid`;
- `StartBlocked`;
- `GoalBlocked`;
- `NoPath`;
- `SearchLimitExceeded`.

## Явные правила вызывающей стороны

Алгоритм не определяет:

- соседство клеток;
- проходимость terrain;
- занятость объектами;
- movement points и стоимость шага;
- диагональное движение;
- влияние типа сущности.

Все эти решения передаются через `IGridTopology` и функцию `canEnter`. `OrthogonalGridTopology` — доступная проектная реализация четырёх направлений, а не утверждение о поведении оригинальной игры.

## Детерминированность

При одинаковых input, порядке соседей и `canEnter` результат одинаков. `OrthogonalGridTopology` перечисляет соседей в порядке up, left, right, down. Изменение этого порядка является изменением контракта выбора между несколькими равными кратчайшими путями.
