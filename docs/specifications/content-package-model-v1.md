# Content package model v1

Это модель собственного контента проекта. Она не содержит и не описывает оригинальные ассеты.

## Назначение

Content package объявляет стабильные ссылки, которыми native scenarios обозначают terrain и инертные object archetypes. Каталог отделяет существование content reference от его будущего визуального ресурса и игровой логики.

## Package

- `formatVersion`: `1`;
- `id`: lowercase package ID;
- `displayName`: отображаемое имя;
- `terrains`: объявления terrain;
- `objectArchetypes`: объявления archetypes.

Каждое объявление содержит локальный `id` и `displayName`. Полная ссылка формируется как `package-id:local-id`. Одинаковый local ID допустим в разных kinds, но ID уникален внутри одного kind одного package.

## Catalog

`ContentCatalog` строится атомарно: если хотя бы один package невалиден или package ID повторяется, частичный каталог не возвращается. Terrain и object archetypes индексируются раздельно, поэтому ссылка правильного синтаксиса, но неправильного kind не считается найденной.

`ScenarioContentValidationService` отдельно проверяет, что default terrain, terrain overrides и object archetypes объявлены. Структурная валидация сценария остаётся независимым первым этапом.

## Границы версии 1

Package v1 не задаёт изображения, аудио, локализацию, проходимость, характеристики или скрипты. Добавление таких контрактов требует отдельной спецификации и модели безопасности.

## JSON persistence

JSON использует camelCase properties, двухпробельный отступ, UTF-8 и завершающий LF. Terrain и object archetype entries сортируются по локальному ID. Неизвестные свойства отклоняются. Встроенный file store принимает документы размером не более 16 MiB и записывает валидные packages через временный файл с атомарной заменой назначения.
