# Участие в проекте

Перед изменениями прочитайте `AGENTS.md` и `ORIGINAL_GAME_FILES.md`.

1. Сохраняйте архитектурные границы и пишите новый код независимо.
2. Добавляйте тесты для нового поведения; используйте только синтетические данные.
3. Помечайте неизвестное как `TODO-D2-RESEARCH`.
4. Выполняйте `dotnet restore`, `dotnet build` и `dotnet test`.
5. Перед коммитом проверяйте `git status` и staged diff на отсутствие оригинальных файлов и секретов.

Коммиты должны быть небольшими и описывать одно законченное изменение. Документация исследования должна явно разделять наблюдения, гипотезы и подтверждённые выводы.
